# Номерной движ

Браузерная игра про коллекционирование автомобильных номеров и собственный гараж.

[Играть на GitHub Pages](https://quaali.github.io/nomernoy-dvizh/) · [Зеркало игры](https://nomera-garage-zakhar.quaali.chatgpt.site)

## Возможности

- Независимая крутка букв, цифр и региона: можно запускать все три одновременно.
- Коллекция номеров и предложения покупателей за игровую валюту.
- 24 машины в магазине и установка номера из коллекции на свободную машину.
- Реалистичные российские номера и покупка жирного начертания.
- Анимация списания денег, бесплатный номер и награда за добровольную рекламу.
- Сохранение прогресса в браузере (`localStorage`).

## Публикация на GitHub Pages

После изменения ветки `main` GitHub Actions автоматически публикует папку `dist` на GitHub Pages. В настройках репозитория Pages выбран источник GitHub Actions.

## Запуск на компьютере

Требуется Python 3. В папке проекта выполните:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте <http://localhost:8000>. Установка зависимостей не нужна.
Основной код, стили и интерфейс находятся в `dist/index.html`, изображения — в `dist/images`.

Локальный прогресс хранится отдельно в каждом браузере. В репозиторий не включены личные сохранения. Все деньги в игре виртуальные. Реклама на обычном локальном сервере может быть недоступна.

## Сборка для Яндекс Игр

```sh
python3 scripts/build_yandex.py
```

Готовый архив: `build/nomernoy-dvizh-yandex.zip`. В нём `index.html` лежит в корне, SDK подключается через `/sdk.js`, добавлены определение языка, сигналы готовности и геймплея, обработка паузы и внутренний скролл.

Эта сборка предназначена для сервера Яндекс Игр. Локально без SDK платформы появится сообщение о невозможности подключения. Для проверки рекламы и платформенных событий используйте debug-панель Яндекс Игр.

Игра ещё не опубликована в Яндекс Играх. Сборка требует проверки в консоли платформы перед отправкой на модерацию. В экспортированной версии добавлены явные теги `head` и `body`, необходимые для проверки архива.
